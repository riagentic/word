## Changes

- **"Jesus" → "*Yeshua*"** (throughout) — Hebrew name preserved throughout.
- **"God" → "*Elohim*"** (vv3–4, 6) — Greek θεός *theos* in the temptation narrative; where Yeshua quotes Deuteronomy the underlying Hebrew is *Elohim*, so the Hebrew divine name is retained.
- **"Peter" → "*Kefa*"** (v18) — Aramaic *Kefa* = rock; Greek *Petros* = Peter. First occurrence in this chapter; name introduced with explanation.
- **"lunatick" → "epileptic"** (v24) — KJV renders Greek σεληνιαζομένους *selēniazomenous* (moon-struck) as "lunatic." Modern equivalent of the described symptoms is epilepsy; "epileptic" used rather than the archaic/pejorative "lunatic."
- **"palsy" → "paralytics"** (v24) — Greek παραλυτικούς *paralutikous* = paralyzed ones. KJV "palsy" is archaic; "paralytics" is direct and accurate.
- **"devils" → "demons"** (v24) — Greek δαιμονιζομένους *daimonizoménous* = demon-possessed. "Devil" in English is diabolos (the satan); Greek *daimōn* is a different word. KJV conflates them.
- **"multitudes" → "crowds"** (v25) — Greek ὄχλοι *ochloi* = crowds, throngs. KJV "multitudes" is not wrong but more archaic.
- **OT quotation v15–16** — Quotes Isa 9:1–2. Matthew follows the LXX with some modifications; rendered to reflect Matthew's Greek text, not the Hebrew MT.

### Notes
- **v4** quotes Deut 8:3.
- **v7** quotes Deut 6:16.
- **v10** quotes Deut 6:13 (the three temptations all countered from Deuteronomy).
- **v15-16** quotes Isa 9:1-2.
